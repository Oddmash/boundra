# Boundra VS Code 0.1.2 (pre-release)

## Release Summary

Make the extension easier to find and guide new users to their first local boundary check.

## Highlights

- Update Marketplace keywords and point to the published user guide.
- Add verified VS Code pre-release install instructions and the official CLI quickstart.

## Installation

```sh
code --install-extension oddmash.boundra-vscode --pre-release
```

Use a trusted workspace and the project-local Boundra CLI.

## Breaking Changes

None intended.

## Known Limitations

Diagnostics use saved files. The Marketplace extension is independently versioned from the npm package.

## Verification

The 0.1.1 pre-release and the npm CLI were verified in clean environments. The extension host tests and VSIX packaging must pass on the exact release commit before publication.
