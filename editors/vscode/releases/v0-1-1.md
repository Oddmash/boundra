# Boundra VS Code 0.1.1 (pre-release)

## Release Summary

Improve installation guidance and workspace diagnostic lifecycle coverage.

## Highlights

- Marketplace setup and project-local CLI instructions.
- Regression coverage for cross-domain rename, trust, virtual workspaces, and workspace folder changes.

## Installation

Install the Boundra pre-release from the Visual Studio Marketplace and use a trusted workspace with the local Boundra CLI.

## Breaking Changes

None intended.

## Known Limitations

The extension is a saved-file diagnostics preview and is independently versioned from the npm package.

## Verification

The extension host, unit tests, and VSIX packaging must pass on the exact release commit.
