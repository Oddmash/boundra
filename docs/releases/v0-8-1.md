# Boundra v0.8.1

## Release Summary

Centralize the development diagnostics overlay design values while preserving the existing browser output and package entrypoints.

## Highlights

- Source overlay colors, typography, spacing and sizing from local JSON. See #196.
- Keep the browser package self-contained. The separately versioned VS Code 0.1.2 pre-release updates Marketplace discovery and first-use documentation.

## Installation

```sh
pnpm add boundra@0.8.1 zod
pnpm exec boundra --version
```

## Breaking Changes

None intended. Existing public entrypoints and overlay behavior are compatible.

## Known Limitations

MCP and LSP remain previews. VS Code Marketplace distribution uses its own verified pre-release workflow.

## Verification

The overlay and native integration tests passed on the reviewed source revision. Chromium, Firefox and WebKit matched the previous computed styles and dismissal behavior at 320px and 1280px. Exact release CI and published package verification are required before announcing availability.
