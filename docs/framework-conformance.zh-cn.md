# 框架使用方一致性验证

发行验收测试针对打包后的包，而非工作区源码别名。在 Node 24 环境中确保 Rust 与 Chromium 可用，执行 `pnpm install --frozen-lockfile`，然后执行 `node scripts/verify-framework-consumers.mjs`。测试创建一次性项目，安装固定版本的使用方依赖，构建 Next.js App Router 和 Vite，并检查实际浏览器输出。它通过编译后的包验证嵌套领域覆盖范围、一个公开别名、结构化的应用引用内部路径诊断，以及输入/结果验证。Vite 开发环境必须包含其开发覆盖层模块；生产环境则不得包含。生产扫描覆盖 JavaScript 和 source map，测试样例会生成 PNG 资源，确保二进制输出不参与文本解码。

该测试样例会记录构建和边界检查耗时作为观测值，而非跨机器性能声明。独立的合成基准测试覆盖 1,000 和 10,000 个源文件。这不能证明与每一种框架配置、打包工具插件、运行时或部署目标都兼容。
