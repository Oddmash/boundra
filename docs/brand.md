# Boundra identity

![Boundra mark](assets/boundra-mark.svg)

The angular B monogram is formed by two architectural planes divided by a deliberate white diagonal seam. The seam represents an explicit interface between domains; the silhouette remains recognizable without an enclosing frame. Orange is a product accent, not a diagnostic error state.

| Token | Value | Use |
| --- | --- | --- |
| Brand | #EA580C | Mark and accents |
| Brand dark | #C2410C | Links or small orange text on white |
| Background | #FFFFFF | Primary surface |
| Text | #171717 | Body text |
| Border | #E7E5E4 | Neutral separators |

Keep the mark clear at small sizes. Preserve its square proportions and surrounding whitespace; use the white-backed SVG on both light and dark documentation backgrounds. Reserve red for errors and use descriptive labels rather than color alone. The angular image-generated concept was translated into an editable SVG for repository use; it replaces the initial rounded-frame concept.
