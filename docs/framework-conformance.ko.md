# 프레임워크 소비자 적합성

릴리스 검증은 워크스페이스 소스 별칭이 아니라 실제 패키징된 패키지를 대상으로 합니다. Rust와 Chromium을 사용할 수 있는 Node 24 환경에서 `pnpm install --frozen-lockfile`을 실행한 다음 `node scripts/verify-framework-consumers.mjs`를 실행하세요. 테스트는 일회용 프로젝트를 만들고, 고정 버전의 소비자 의존성을 설치하며 Next.js App Router와 Vite를 빌드하고 실제 브라우저 출력을 검사합니다. 중첩 도메인의 스캔 범위, 공개 별칭, 애플리케이션에서 내부 경로로 import했을 때의 구조화된 진단, 컴파일된 패키지를 통한 입력/결과 검증을 확인합니다. Vite 개발 환경에는 개발 오버레이 모듈이 포함되어야 하지만 프로덕션에는 포함되어서는 안 됩니다. 프로덕션 스캔은 JavaScript와 소스 맵을 대상으로 하며, 픽스처는 텍스트 디코딩에서 바이너리 산출물이 제외되는지 확인하기 위해 PNG 애셋을 생성합니다.

픽스처는 빌드 및 경계 검사 소요 시간을 서로 다른 기기 간 성능 주장으로 사용하지 않고 관찰값으로 기록합니다. 별도의 합성 벤치마크는 소스 파일 1,000개 및 10,000개를 대상으로 합니다. 이는 모든 프레임워크 설정, 번들러 플러그인, 런타임 또는 배포 대상과의 호환성을 입증하는 것은 아닙니다.
