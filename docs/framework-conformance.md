# Framework consumer conformance

The release gate exercises the packed package, not workspace source aliases. Run `pnpm install --frozen-lockfile`, then `node scripts/verify-framework-consumers.mjs` on Node 24 with Rust and Chromium available. The test creates a disposable project, installs pinned consumer dependencies, builds Next.js App Router and Vite, and checks the actual browser output. It verifies nested-domain coverage, a public alias, a structured application-to-internal-import diagnostic, and input/result validation through the compiled package. Vite development must include its development overlay module; production must not.

The fixture records build and boundary-check duration as observations, not cross-machine performance claims. The separate synthetic benchmark exercises 1,000 and 10,000 source files. This is not proof of compatibility with every framework configuration, bundler plugin, runtime or deployment target.
