# フレームワーク利用側の適合性

リリースゲートはワークスペースのソースエイリアスではなく、パックされたパッケージを検証します。Rust と Chromium を使用できる Node 24 環境で `pnpm install --frozen-lockfile` を実行してから `node scripts/verify-framework-consumers.mjs` を実行してください。テストは使い捨てプロジェクトを作成し、固定された利用側依存関係をインストールし、Next.js App Router と Vite をビルドして、実際のブラウザー出力を検査します。ネストされたドメインのカバレッジ、公開エイリアス、アプリケーションから内部 import への構造化診断、コンパイル済みパッケージを通じた入力・結果の検証を確認します。Vite の開発ビルドには開発オーバーレイモジュールが含まれていなければならず、プロダクションビルドには含まれてはいけません。プロダクションのスキャンは JavaScript とソースマップを対象とし、バイナリ出力をテキストデコードから除外していることを確認するため、フィクスチャは PNG アセットを出力します。

フィクスチャはビルドと境界チェックの所要時間を観測値として記録するもので、異なるマシン間での性能を主張するものではありません。別の合成ベンチマークは1,000と10,000のソースファイルを検証します。あらゆるフレームワーク設定、バンドラープラグイン、ランタイム、デプロイ先との互換性を証明するものではありません。
